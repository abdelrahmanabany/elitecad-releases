# EliteCAD downloads

EliteTFM's in-office drafting app: 2D CAD with DWG/DXF, shared drawings that several people edit at once (online or offline), and agent access over MCP.

## Download

| | |
|---|---|
| **Windows installer** (recommended) | [EliteCAD-Setup.exe](https://github.com/abdelrahmanabany/elitecad-releases/releases/latest/download/EliteCAD-Setup.exe) |
| Windows, no install (zip) | [EliteCAD-win.zip](https://github.com/abdelrahmanabany/elitecad-releases/releases/latest/download/EliteCAD-win.zip) |
| Linux (AppImage) | [EliteCAD.AppImage](https://github.com/abdelrahmanabany/elitecad-releases/releases/latest/download/EliteCAD.AppImage) |
| Source code | [EliteCAD-source.zip](https://github.com/abdelrahmanabany/elitecad-releases/releases/latest/download/EliteCAD-source.zip) |

The builds aren't code-signed yet. On Windows, if SmartScreen warns, click **More info → Run anyway**. On Linux, make the AppImage executable (`chmod +x EliteCAD.AppImage`).

## Set up

1. Install on each computer.
2. On first start, type your name. In Settings, type the office key (the same on every computer). Leave "Sync server" empty.
3. Computers on the same office network find each other on their own. Share a drawing (`SHARE`), others `JOIN` it.
